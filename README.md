# cheele

Claude, but it actually lets you think. One point at a time, zero rushing, and a lazy "yep" doesn't count as agreeing to anything. Once you've figured it out, it hands you a clean prompt for Claude Code to go build. Say `/cheele` or "conversational mode" and chill.

## Install

Paste this into Claude Code and let it cook:

```
Install the cheele skill from https://github.com/ajtazer/Cheele: clone it to a temp folder, copy its cheele/ folder to ~/.claude/skills/cheele (create ~/.claude/skills if needed), delete the temp clone, and confirm ~/.claude/skills/cheele/SKILL.md exists.
```
